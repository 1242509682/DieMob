# DieMob 怪物保护区

- 作者: Zaicon、羽学
- 出处: TShock官方群816771079
- 这是一个Tshock服务器插件，主要用于：为区域添加怪物保护选项,适配TShock 6.1.0

## 指令

| 语法           |        权限         |   说明   |
| -------------- | :-----------------: | :------: |
| /dmb s | diemob | 列出所有区域 |
| /dmb s <区域名> | diemob | 给指定区域设置/取消保护区 |
| /dmb rp <区域名> | diemob | 查看玩家附近NPC类型 |
| /dmb rp <区域名> [页]  | diemob | 查看指定区域的怪物替换表 |
| /dmb rp ls [页]  | diemob | 列出所有已设置的保护区 |
| /dmb if <区域名> | diemob | 查看指定保护区的详细信息 |
| /dmb ms | diemob | 设置进出消息开关 |
| /dmb reset | diemob | 清空所有保护区配置 |
| /reload | tshock.cfg.reload | 重新加载配置文件及保护区缓存 |
| /dmb up <区域名> <选项> ... | diemob | 修改保护区的参数 |

## 可用选项(支持字母和数字)：

```
1.类型(t) 杀死(k)/击退(kb)  —— 设置区域处理类型
2.友好(f) —— 影响友好NPC(开启则关闭,关闭则开启)
3.雕像(s) —— 影响雕像生成的怪物(开启则关闭,关闭则开启)
4.替换(r) 原ID [新ID] —— 有2个ID则添加/更新，只有1个则删除
5.描述(d) [文本] —— 设置或清空区域描述（留空则清空）
6.进入消息(j) [文本]  —— 设置或清空区域进入消息（留空则清空）
7.离开消息(l) [文本]  —— 设置或清空区域离开消息（留空则清空）
8.显示占位符(zwf) ——同时教学示例描述写法
```

## 配置与缓存

```json
插件配置文件位于 tshock/怪物保护区/配置文件.json ：
{
  "插件开关": true,
  "进出消息": true,
  "更新间隔": 1000,
  "排斥力修正系数": 1.0,
  "区域拉伸": 10
}

区域数据文件位于 tshock/怪物保护区/数据缓存_世界ID.json ，示例：
[
  {
    "区域名称": "草药园",
    "处理类型(0杀死,1击退)": 1,
    "替换表": {
      "1": 2,
      "3": 5
    },
    "影响友方NPC": false,
    "影响雕像生成": false,
    "进入消息": "保护类型:{保护}\n影响友好NPC:{友好}\n影响雕像刷怪:{雕像}\n替换怪物数:{替换}个\n查看列表: /dmb rp {区域名}\n欢迎进入区域 [c/FFD700:{区域名}]",
    "离开消息": "你已离开区域 [c/FFD700:{区域名}]",
    "区域描述": ""
  }
]
```
